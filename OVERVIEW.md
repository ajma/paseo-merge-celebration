Merge celebration plays colorful confetti across your current Paseo desktop or browser window when a workspace is archived after its GitHub pull request has merged. A recap shows the PR title and excerpts from up to three linked closing issues. Confetti keeps falling while the recap is open. Dismiss it to stop new confetti and let the remaining pieces drift offscreen. Events received while the same connected window is hidden wait for visibility before animating. Preview merge celebration is available in the Command Center.

Settings → Plugins → Merge celebration lets you turn live celebrations off, pick the headline verb (shipped, landed, merged, committed or deployed) and emoji, hide the issue recap, and turn confetti off or change its size, speed and amount. Settings are saved on the daemon and shared by every client connected to it.

Works with the stock Paseo 0.11.2 desktop/browser client and daemon. No app patch, rebuild or daemon restart is needed. Git and an authenticated GitHub CLI must be available on the daemon machine. Native iOS and Android clients do not contribute celebration UI. The fullscreen layer uses browser-specific mounting from the plugin; Paseo does not provide a portable global overlay API.

Open, closed without merging, mismatched and unverifiable PRs stay silent. Verified celebrations wait up to 24 hours for a desktop or browser client to display them, including after a disconnect. Up to 100 pending events are held in memory; a plugin reload or daemon restart clears them. Displayed celebrations do not replay on reconnect. Reduced motion disables falling confetti. Repository and issue reads go through the GitHub CLI to github.com using your existing credentials. Issue recaps use plain text excerpts, with no AI service.
